# ClosedLoop AI

Product-intelligence platform that turns customer conversations and feedback (Gong, Fireflies, Slack, Zendesk, Intercom, Salesforce, HubSpot, surveys, product usage; 40+ integrations) into structured, source-traceable product insights, themes, buildable features, and prioritized roadmap decisions. Exposes a read-only /v1 REST API, a hosted MCP server, an llms.txt index, and published Claude Code skills.

## APIs

- **ClosedLoop AI REST API** — Read-only /v1 REST API, team- and region-scoped, authenticated via X-API-Key. Exposes insights, products, themes, features, coverage/evidence, customers, customer context, competitors, trends, facets, integrations, usage/credits, and a public health check. Feedback is ingested via integrations, not written through this API. (`https://api.closedloop.sh/v1`)
- **ClosedLoop AI MCP Server** — Hosted, first-class MCP server over HTTP with OAuth auth (interactive auto-registration or client_credentials for M2M). Ships MCP tools (query insights, context, customers, themes, competitors) and a 'prd' prompt/slash command. Works with Claude Code, Claude Desktop/web/Cowork, Cursor, LiteLLM, or any MCP-compatible client. US endpoint https://mcp.closedloop.sh, EU endpoint https://eu.mcp.closedloop.sh. (`https://mcp.closedloop.sh`)
- **ClosedLoop AI Claude Code Skills** — Set of ~25 pre-built Claude Code skills distributed as the 'closedloop-skills' plugin via the Anthropic community marketplace, grouped by team (product/eng/sales/marketing/CS/leadership). Examples: Deep Dive, PM Prep, Scope Guard, Synthetic Customer, Competitor Gap, Bug Blast Radius, Weekly Brief, Ship Notify, Case Study Scout. (`https://closedloop.sh/docs/skills/overview`)
